FAQ

No menu-bar icon

Open InfiniWake Settings and enable “Show menu bar icon”. Make sure the app runs from /Applications.

Caps Lock lamp does not stay on

Grant Accessibility to InfiniWake, then quit the app completely and reopen it. Keep-awake still works without the lamp.

Closed-lid mode

Install the optional helper from the repository (scripts/install-helper.sh). The base power assertion is intended for an open lid.

Gatekeeper blocks launch

For ad-hoc GitHub builds: right-click the app → Open, or allow it under Privacy & Security.

What to include in email

  • macOS and InfiniWake versions;
  • chip (Apple Silicon / Intel);
  • expected vs actual behavior;
  • settings screenshot (optional).
